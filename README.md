# 公考刷题库

个人在线题库，参考成熟刷题产品的学习路径，包含：

- 课程章节
- 真题试卷
- 专项练习
- 随机抽题
- 错题本
- 收藏题
- 学习记录
- 电脑/手机响应式使用
- 前端密码门禁

在线地址：<https://linfukai186-arch.github.io/gongkao-tiku/>

## 使用方式

1. 打开在线地址。
2. 输入访问密码：`kaogong2026`。
3. 选择国考、省考或事业编。
4. 选择科目。
5. 进入学习章节、专项练习或真题试卷。
6. 错题和收藏会保存在当前浏览器中。

手机端可在浏览器菜单中选择“添加到主屏幕”。

## 课程结构

课程入口按以下路径组织：

```text
考试类别
  └─ 科目
      ├─ 学习章节
      │   └─ 知识点 → 专项练习
      ├─ 真题试卷
      ├─ 随机抽题
      ├─ 错题本
      └─ 收藏题
```

国考/省考行测：常识判断、言语理解、数量关系、判断推理、资料分析。

申论：归纳概括、综合分析、提出对策、贯彻执行、申发论述。

事业编公基：政治理论、法律基础、经济管理、公文写作、科技人文。

事业编综应：案例分析、实务处理、公文写作、材料作文。

## 数据来源与版权边界

- 真题数据来自公开可访问、适合整理的资料源，并保留来源/年份/卷别字段。
- 公开资料整理与原创练习会明确区分。
- 不复制粉笔的品牌、课程文案、受版权保护的题目、解析或页面素材。
- “参考粉笔”指参考课程化的学习路径和功能组织，不代表粉笔官方内容。
- 真题和公开资料的具体再分发权限应由使用者自行确认。

## 项目文件

- `index.html`：页面结构
- `style.css`：响应式样式
- `app.js`：课程、刷题、判分、错题、收藏、学习记录
- `bank.js`：题库目录和按需加载
- `course.js`：课程章节配置
- `practice.js`：练习题加载器
- `data.js` / `data-extra.js`：少量内置种子题
- `lock.js`：前端密码门禁
- `data/<模块>/index.json`：试卷索引
- `data/<模块>/y<年份>.json`：按年份试卷数据
- `data/practice/<模块>.json`：原创练习题包

## 本地开发

由于题库使用 `fetch()` 按需读取 JSON，建议通过 HTTP 静态服务器运行，而不是直接双击 HTML：

```bash
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

## 私有访问说明

当前 GitHub Pages 是公开站点，页面增加了密码门禁，适合个人低调使用，但这不是服务端安全认证。具备开发者工具能力的人仍可能读取前端数据。

如需真正只允许本人访问，应使用：

- 私有 GitHub 仓库 + 私有 Pages（通常需要相应付费方案）
- Cloudflare Access
- Vercel/Netlify 身份验证
- 自建服务器登录系统
